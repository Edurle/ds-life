# Rust-Lua 自迭代 Agent 系统——零基础完整实施指南

本指南假设读者仅具备基本编程概念（变量、函数、命令行的使用），无需任何 Rust、Lua、Anthropic API 或终端 UI 经验。每一个步骤都包含完整命令和代码，按顺序执行后即可构建出完整的可自迭代智能体系统。

---

## 准备工作：安装基础工具

### 1. 安装 Rust
打开终端（Linux/macOS 为 Terminal，Windows 推荐使用 PowerShell 或 WSL），执行：
```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
按提示选择默认安装（选项1），等待完成。然后重启终端或执行：
```sh
source "$HOME/.cargo/env"
```
验证安装：
```sh
rustc --version
cargo --version
```

### 2. 安装 Lua（仅供本地测试用，非必须）
项目内嵌 Lua，无需单独安装。但为了调试，可安装：
- Ubuntu: `sudo apt install lua5.4`
- macOS: `brew install lua`
- Windows: 从 [LuaBinaries](http://luabinaries.sourceforge.net/) 下载

### 3. 安装 Git
- `git --version` 若未找到，从 [git-scm.com](https://git-scm.com/downloads) 下载安装。

### 4. 设置 Anthropic API Key
注册 [Anthropic Console](https://console.anthropic.com/) 获取 API 密钥。在终端中设置环境变量（不同系统方式不同）：
- Linux/macOS: 在 `~/.bashrc` 或 `~/.zshrc` 添加 `export ANTHROPIC_API_KEY="你的密钥"`
- Windows (PowerShell): `$env:ANTHROPIC_API_KEY="你的密钥"` 或通过系统环境变量设置。

### 1.2 编辑 `Cargo.toml` 添加依赖
用文本编辑器（如 VS Code）打开 `agent_host/Cargo.toml`，替换内容为：

```toml
[dependencies]
```

说明：
- `mlua` 内嵌 Lua 5.4 解释器，`vendored` 会自动编译 Lua C 源码，不需要系统安装 Lua。

- `tokio` 异步运行时，用于 TUI 事件循环和看门狗。
- `reqwest` 用于调用 Anthropic API。
- `serde` / `serde_json` 处理 JSON。
- `uuid` 生成编辑会话 ID。
- `ratatui` + `crossterm` 构建 TUI。

### 2.2 安全文件读写工具 (`fs.rs`)
```rust
use std::path::{Path, PathBuf};
use std::fs;

const WORKDIR: &str = "."; // 后续可配置为环境变量

fn safe_path(path: &str) -> anyhow::Result<PathBuf> {
    let base = std::env::current_dir()?;
    let full = base.join(path);
    let canonical = full.canonicalize()?;
    if !canonical.starts_with(&base) {
        anyhow::bail!("Access denied: path escapes workspace");
    }
    Ok(canonical)
}

pub fn read_file(path: &str, limit: Option<usize>) -> anyhow::Result<String> {
    let path = safe_path(path)?;
    let content = fs::read_to_string(&path)?;
    let lines: Vec<&str> = content.lines().collect();
    if let Some(lim) = limit {
        if lim < lines.len() {
            let mut output = lines[..lim].join("\n");
            output.push_str(&format!("\n... ({} more lines)", lines.len() - lim));
            return Ok(output);
        }
    }
    Ok(content)
}

pub fn write_file(path: &str, content: &str) -> anyhow::Result<String> {
    let path = safe_path(path)?;
    if let Some(parent) = path.parent() {
        fs::create_dir_all(parent)?;
    }
    fs::write(&path, content)?;
    Ok(format!("Wrote {} bytes to {}", content.len(), path.display()))
}
```

### 2.3 Bash 工具 (`bash.rs`)

```rust
use std::process::Command;

pub fn run_bash(command: &str) -> anyhow::Result<String> {
    let dangerous = ["rm -rf /", "sudo", "shutdown", "reboot", "> /dev/", "mkfs", "dd if="];
    for d in dangerous {
        if command.contains(d) {
            anyhow::bail!("Dangerous command blocked");
        }
    }
    let output = Command::new("sh")
        .arg("-c")
        .arg(command)
        .output()?;
    let stdout = String::from_utf8_lossy(&output.stdout);
    let stderr = String::from_utf8_lossy(&output.stderr);
    let combined = format!("{}{}", stdout, stderr);
    Ok(if combined.trim().is_empty() {
        "(no output)".into()
    } else {
        // 限制输出长度
        if combined.len() > 50000 {
            format!("{}... (truncated)", &combined[..50000])
        } else {
            combined
        }
    })
}
```

### 2.5 在主程序中注册工具到 Lua
现在改造 `main.rs` 来创建 Lua 环境并注入工具。注意这一步暂未加入 TUI，仅用命令行测试。
```rust
use mlua::{Lua, Function, Table};
use std::sync::Arc;

mod tools;

fn create_lua() -> anyhow::Result<Lua> {
    let lua = Lua::new();

    // 沙箱：移除危险函数
    lua.globals().set("os", lua.create_table()?)?;
    lua.globals().set("io", lua.create_table()?)?;

    // 注入 host 表
    let host = lua.create_table()?;

    // read_file
    let host_read = lua.create_function(|_, (path, limit): (String, Option<usize>)| {
        tools::fs::read_file(&path, limit).map_err(|e| mlua::Error::external(e))
    })?;
    host.set("read_file", host_read)?;

    // write_file
    let host_write = lua.create_function(|_, (path, content): (String, String)| {
        tools::fs::write_file(&path, &content).map_err(|e| mlua::Error::external(e))
    })?;
    host.set("write_file", host_write)?;

    // bash
    let host_bash = lua.create_function(|_, cmd: String| {
        tools::bash::run_bash(&cmd).map_err(|e| mlua::Error::external(e))
    })?;
    host.set("bash", host_bash)?;

    // llm_chat (同步包装异步？目前先用模拟，后续用真实)
    // 暂时注册一个返回固定字符串的函数
    let host_llm = lua.create_function(|_, _msg: String| {
        Ok("{\"content\":[{\"type\":\"text\",\"text\":\"mock\"}], \"stop_reason\":\"end_turn\"}")
    })?;
    host.set("llm_chat", host_llm)?;

    lua.globals().set("host", host)?;
    Ok(lua)
}

fn main() -> anyhow::Result<()> {
    let lua = create_lua()?;
    // 执行测试脚本
    lua.load("print(host.read_file('Cargo.toml', 3))").exec()?;
    Ok(())
}
```

### 3.2 编写 `main_loop.lua`
创建 `agent_plugins/system_core/main_loop.lua`：
```lua
-- Agent 主循环
local SYSTEM_PROMPT = [[
You are a coding agent. Use tools to solve tasks. Act, don't explain.
]]

local function run_agent(task, max_steps)
    max_steps = max_steps or 10
    local messages = { {role = "user", content = task} }
    
    for step = 1, max_steps do
        local response_str = host.llm_chat(messages)  -- 暂时需要实现解析
        -- 解析 JSON 响应
        local ok, response = pcall(json.decode, response_str)
        if not ok then
            return "Failed to parse LLM response: " .. tostring(response_str)
        end
        
        local stop_reason = response.stop_reason
        local content = response.content
        
        -- 构建 assistant 消息
        local assistant_msg = {role = "assistant", content = content}
        table.insert(messages, assistant_msg)
        
        if stop_reason == "end_turn" then
            -- 提取文本响应
            for _, block in ipairs(content) do
                if block.type == "text" then
                    return block.text
                end
            end
            return "No text in final response"
        end
        
        -- 处理工具调用
        local tool_results = {}
        for _, block in ipairs(content) do
            if block.type == "tool_use" then
                local tool_name = block.name
                local tool_args = block.input or {}
                local handler = host[tool_name]
                if handler then
                    local ok2, result = pcall(handler, table.unpack(tool_args))
                    if not ok2 then result = "Error: " .. tostring(result) end
                    table.insert(tool_results, {
                        type = "tool_result",
                        tool_use_id = block.id,
                        content = tostring(result)
                    })
                else
                    table.insert(tool_results, {
                        type = "tool_result",
                        tool_use_id = block.id,
                        content = "Unknown tool: " .. tool_name
                    })
                end
            end
        end
        table.insert(messages, {role = "user", content = tool_results})
    end
    return "Task step limit exceeded"
end

return { run_agent = run_agent }
```

**注意**：这里依赖 `json` 模块解析，Lua 不自带 JSON，需要一个 JSON 解析器。我们可以通过 Rust 注入 `json.decode` 和 `json.encode`，或者使用纯 Lua 实现。最简单的方法是将 `serde_json` 的能力暴露给 Lua。下面我们在 Rust 中注入 `json` 表。

### 3.3 在 Rust 中注入 JSON 工具
在 `create_lua` 函数中添加：
```rust
let json = lua.create_table()?;
let json_decode = lua.create_function(|_, s: String| {
    let val: serde_json::Value = serde_json::from_str(&s).map_err(|e| mlua::Error::external(e))?;
    // 将 serde_json::Value 转换为 Lua 值
    let lua_val = value_to_lua(&lua, &val)?;
    Ok(lua_val)
})?;
json.set("decode", json_decode)?;

let json_encode = lua.create_function(|_, val: mlua::Value| {
    let rust_val = lua_to_value(&lua, val)?;
    let s = serde_json::to_string(&rust_val).map_err(|e| mlua::Error::external(e))?;
    Ok(s)
})?;
json.set("encode", json_encode)?;
lua.globals().set("json", json)?;
```

需要实现两个辅助函数 `value_to_lua` 和 `lua_to_value`，这里给出最简单的实现（只处理常用类型），加入 `src/main.rs`：
```rust
use mlua::Value as LuaValue;
use serde_json::{Value as JsonValue, Map};

fn value_to_lua(lua: &Lua, val: &JsonValue) -> mlua::Result<LuaValue> {
    match val {
        JsonValue::Null => Ok(LuaValue::Nil),
        JsonValue::Bool(b) => Ok(LuaValue::Boolean(*b)),
        JsonValue::Number(n) => {
            if let Some(i) = n.as_i64() {
                Ok(LuaValue::Integer(i as i32))
            } else {
                Ok(LuaValue::Number(n.as_f64().unwrap_or(0.0)))
            }
        }
        JsonValue::String(s) => Ok(LuaValue::String(lua.create_string(s)?)),
        JsonValue::Array(arr) => {
            let tbl = lua.create_table()?;
            for (i, v) in arr.iter().enumerate() {
                tbl.set(i+1, value_to_lua(lua, v)?)?;
            }
            Ok(LuaValue::Table(tbl))
        }
        JsonValue::Object(obj) => {
            let tbl = lua.create_table()?;
            for (k, v) in obj.iter() {
                tbl.set(k.clone(), value_to_lua(lua, v)?)?;
            }
            Ok(LuaValue::Table(tbl))
        }
    }
}

fn lua_to_value(lua: &Lua, val: LuaValue) -> mlua::Result<JsonValue> {
    match val {
        LuaValue::Nil => Ok(JsonValue::Null),
        LuaValue::Boolean(b) => Ok(JsonValue::Bool(b)),
        LuaValue::Integer(i) => Ok(JsonValue::Number(i.into())),
        LuaValue::Number(n) => {
            // 简单处理，转为数字
            serde_json::Number::from_f64(n).map(JsonValue::Number)
                .ok_or_else(|| mlua::Error::external("invalid float"))
        }
        LuaValue::String(s) => Ok(JsonValue::String(s.to_str()?.to_owned())),
        LuaValue::Table(tbl) => {
            // 判断是数组还是字典
            let len = tbl.len()?;
            if len > 0 {
                // 数组
                let mut arr = Vec::new();
                for i in 1..=len {
                    let v = tbl.get::<i32, LuaValue>(i)?;
                    arr.push(lua_to_value(lua, v)?);
                }
                Ok(JsonValue::Array(arr))
            } else {
                // 字典
                let mut map = Map::new();
                for pair in tbl.pairs::<String, LuaValue>() {
                    let (k, v) = pair?;
                    map.insert(k, lua_to_value(lua, v)?);
                }
                Ok(JsonValue::Object(map))
            }
        }
        _ => Err(mlua::Error::external("unsupported Lua type")),
    }
}
```

现在 `main_loop.lua` 可以使用 `json.decode` 解析 LLM 返回的字符串。

## 第4步：连接真实 Anthropic API

### 4.1 更新 `llm.rs`

```rust
use serde_json::{json, Value};

pub async fn llm_chat(api_key: &str, model: &str, messages: Value) -> anyhow::Result<String> {
    let client = reqwest::Client::new();
    let body = json!({
        "model": model,
        "max_tokens": 4096,
        "messages": messages,
    });
    let resp = client.post("https://api.anthropic.com/v1/messages")
        .header("x-api-key", api_key)
        .header("anthropic-version", "2023-06-01")
        .json(&body)
        .send()
        .await?;

    Ok(text)
}
```

## 第6步：实现自我迭代机制（编辑会话）

### 6.1 创建 `self_update.rs`
放在 `src/tools/self_update.rs`。包含编辑会话管理、`update_plugin` 等。
```rust
use std::collections::HashMap;
use std::sync::Mutex;
use uuid::Uuid;
use std::process::Command;

lazy_static::lazy_static! {
    static ref SESSIONS: Mutex<HashMap<String, EditSession>> = Mutex::new(HashMap::new());
}

pub struct EditSession {
    pub id: String,
    pub files_changed: Vec<String>,
    pub base_commit: String,
}

fn git_commit(message: &str) -> anyhow::Result<()> {
    Command::new("git").args(&["add", "."]).status()?;
    Command::new("git").args(&["commit", "-m", message]).status()?;
    Ok(())
}

pub fn start_session() -> anyhow::Result<String> {
    let id = Uuid::new_v4().to_string();
    let base = String::from_utf8(
        Command::new("git").args(&["rev-parse", "HEAD"]).output()?.stdout
    )?.trim().to_string();
    let session = EditSession {
        id: id.clone(),
        files_changed: vec![],
        base_commit: base,
    };
    SESSIONS.lock().unwrap().insert(id.clone(), session);
    Ok(id)
}

pub fn update_plugin(session_id: &str, file_name: &str, content: &str) -> anyhow::Result<String> {
    let mut sessions = SESSIONS.lock().unwrap();
    let session = sessions.get_mut(session_id).ok_or_else(|| anyhow::anyhow!("Session not found"))?;
    // 限制只能在 system_core/ 下
    if !file_name.starts_with("system_core/") {
        anyhow::bail!("Can only modify files under system_core/");
    }
    let path = std::path::Path::new("agent_plugins").join(file_name);
    std::fs::create_dir_all(path.parent().unwrap())?;
    std::fs::write(&path, content)?;
    session.files_changed.push(file_name.to_string());
    Ok(format!("Updated {}", file_name))
}

pub fn commit_session(session_id: &str, message: &str) -> anyhow::Result<String> {
    let sessions = SESSIONS.lock().unwrap();
    let session = sessions.get(session_id).ok_or_else(|| anyhow::anyhow!("Session not found"))?;
    let full_message = format!("{} [session:{}]", message, session_id);
    git_commit(&full_message)?;
    Ok(format!("Committed session {}", session_id))
}

pub fn rollback_session(session_id: &str) -> anyhow::Result<String> {
    let mut sessions = SESSIONS.lock().unwrap();
    let session = sessions.remove(session_id).ok_or_else(|| anyhow::anyhow!("Session not found"))?;
    // checkout files
    for file in &session.files_changed {
        Command::new("git").args(&["checkout", "--", file]).status()?;
    }
    Ok("Rolled back".to_string())
}
```

添加到 `tools/mod.rs`。

## 第7步：崩溃检测与回滚

### 7.1 在 Rust 中添加滑动窗口检测器
创建 `src/recovery.rs`：
```rust
use std::collections::VecDeque;
use std::sync::Mutex;

pub struct CrashDetector {
    window: VecDeque<bool>,
    max_size: usize,
    consecutive_failures: usize,
    failure_count: usize,
}

impl CrashDetector {
    pub fn new(window_size: usize) -> Self {
        Self {
            window: VecDeque::with_capacity(window_size),
            max_size: window_size,
            consecutive_failures: 0,
            failure_count: 0,
        }
    }

    pub fn record(&mut self, success: bool) {
        self.window.push_back(success);
        if self.window.len() > self.max_size {
            self.window.pop_front();
        }
        if !success {
            self.consecutive_failures += 1;
            self.failure_count += 1;
        } else {
            self.consecutive_failures = 0;
        }
    }

    pub fn should_rollback(&self, threshold: f64, max_consecutive: usize) -> bool {
        let total = self.window.len() as f64;
        if total < self.max_size as f64 { return false; }
        let failure_rate = self.failure_count as f64 / total;
        failure_rate >= threshold || self.consecutive_failures >= max_consecutive
    }
}
```

### 7.2 在主循环中集成
在 `main.rs` 任务执行前后调用检测器，如果需要回滚则执行 `git reset --hard HEAD~1` 并重建 Lua 环境。具体实现可在 `run_agent` 包装函数里。

示例代码片段（在 `main.rs` 中）：
```rust
let mut detector = recovery::CrashDetector::new(5);
loop {
    let result = std::panic::catch_unwind(|| {
        // 执行 agent_loop 调用
    });
    let success = result.is_ok();
    detector.record(success);
    if detector.should_rollback(0.6, 3) {
        eprintln!("Crash detected, rolling back...");
        Command::new("git").args(&["reset", "--hard", "HEAD~1"]).status().unwrap();
        // 重建 Lua 等
    }
}
```

## 第9步：TUI 构建

### 9.1 基础 TUI 循环
新建 `src/tui.rs`：
```rust
use ratatui::backend::CrosstermBackend;
use ratatui::Terminal;
use crossterm::event::{self, Event, KeyCode};
use crossterm::execute;
use crossterm::terminal::{disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen};
use std::io;

pub fn run_tui() -> anyhow::Result<()> {
    enable_raw_mode()?;
    let mut stdout = io::stdout();
    execute!(stdout, EnterAlternateScreen)?;
    let backend = CrosstermBackend::new(stdout);
    let mut terminal = Terminal::new(backend)?;

    // 主循环
    loop {
        terminal.draw(|f| {
            // 这里调用 Lua render_config 获取布局并渲染（简化示例）
            let text = ratatui::text::Text::from("Agent TUI - type your message:");
            f.render_widget(text, f.size());
        })?;

        if event::poll(std::time::Duration::from_millis(100))? {
            if let Event::Key(key) = event::read()? {
                if key.code == KeyCode::Esc {
                    break;
                }
            }
        }
    }

    disable_raw_mode()?;
    execute!(terminal.backend_mut(), LeaveAlternateScreen)?;
    Ok(())
}
```

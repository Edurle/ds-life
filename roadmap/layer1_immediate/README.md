# Layer 1：立即可做的增强

改动量小（每个 0.5~1 天），但对用户体验提升显著。

## 子功能列表

| # | 功能 | 文件 | 状态 |
|---|------|------|------|
| 01 | 流式输出 | [01_streaming.md](01_streaming.md) | 设计中 |
| 02 | 对话持久化 | [02_persistence.md](02_persistence.md) | 设计中 |
| 03 | 命令系统（Slash 命令） | [03_shortcuts.md](03_shortcuts.md) | 设计中 |
| 04 | 文件监视器 | [04_file_watcher.md](04_file_watcher.md) | 设计中 |
| 05 | TUI 体验打磨（自适应布局 + 滚动翻页） | [05_tui_ux.md](05_tui_ux.md) | 设计中 |

## 设计决策

| 问题 | 结论 |
|------|------|
| 快捷键 vs 命令 | **命令模式**（`/clear` 等），避免与 tmux/screen 冲突 |
| 内容溢出 | **PageUp/PageDown/Home/End 滚动**，而非截断 |
| 布局 | **自适应**（`Percentage(85)`），随窗口大小变化 |
| 执行方式 | 命令行**不消耗 API Token**，由 Rust 侧处理 |

## 实施顺序建议

1. **TUI 体验打磨**（05）— 先解决滚动和自适应，让 TUI 可用
2. **命令系统**（03）— 依赖 05 的 `TuiState` 重构
3. **流式输出**（01）— 核心体验跃升，依赖 05 的渲染模式
4. **对话持久化**（02）— 依赖 03 的 /save /history 命令
5. **文件监视器**（04）— 独立，可随时插入

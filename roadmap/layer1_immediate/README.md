## 实施顺序建议

1. **快捷键系统** → 让 TUI 可用（Ctrl+S/L/R/Esc），不依赖其他模块
2. **流式输出** → TUI 体验核心跃升
3. **对话持久化** → 快捷键依赖 SQLite 结构，流式输出后接入
4. **文件监视器** → 相对独立，可随时插入

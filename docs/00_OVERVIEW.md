# Rust-Lua 自迭代 Agent 系统 — 实施总览

## 架构

```
┌─────────────────────────────────────┐
│         Rust 宿主 (agent_host)       │
│  ┌─────────────────────────────┐    │
│  │  main.rs                    │    │
│  │  ├── create_lua()           │    │
│  │  ├── Anthropic API 调用     │    │
│  │  ├── TUI / CLI 模式选择     │    │
│  │  └── 崩溃检测 + 回滚        │    │
│  └─────────────────────────────┘    │
│  ┌─────────────────────────────┐    │
│  │  tools/                     │    │
│  │  ├── fs.rs   文件读写沙箱    │    │
│  │  ├── bash.rs  安全 shell    │    │
│  │  ├── llm.rs   API 客户端    │    │
│  │  └── self_update.rs 自修改  │    │
│  └─────────────────────────────┘    │
│  ┌─────────────────────────────┐    │
│  │  recovery.rs  崩溃检测器    │    │
│  └─────────────────────────────┘    │
│  ┌─────────────────────────────┐    │
│  │  tui.rs   终端 UI (可选)    │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
         │ host.xxx 工具注入
         ▼
┌─────────────────────────────────────┐
│     Lua Agent 层 (agent_plugins/)   │
│  system_core/                       │
│  ├── main_loop.lua    主循环        │
│  ├── self_improve.lua 自我迭代      │
│  ├── skill_loader.lua 技能加载      │
│  └── sub_agent.lua    子智能体      │
│  skills/  技能定义                  │
│  config/  配置                      │
│  memory/  持久存储                  │
└─────────────────────────────────────┘
```

## 核心循环

```
用户输入 → LLM (Anthropic API) → tool_use → Lua 调用 Rust 工具
     → tool_result → LLM 分析 → 最终回答 → 用户
         ↑                                    |
         └── 自我迭代反馈循环 ──────────────────┘
```

## 文件结构

```
ds-life/
├── docs/                   ← 按步骤拆分的实施指南
├── agent_host/             ← Rust 项目 (cargo new)
│   ├── Cargo.toml
│   └── src/
│       ├── main.rs
│       ├── tools/{mod,fs,bash,llm,self_update}.rs
│       ├── recovery.rs
│       └── tui.rs
├── agent_plugins/          ← Lua 插件系统
│   ├── system_core/        (Agent 大脑)
│   ├── skills/             (技能定义)
│   ├── config/             (配置文件)
│   └── memory/             (持久化存储)
└── scripts/                (测试脚本)
```

## 实施步骤（10步）

| 步骤 | 内容 | 产出 |
|------|------|------|
| 01 | 安装工具 + 创建项目 | 可编译的空 Rust 项目 |
| 02 | 沙箱 + 工具 | 文件读写、bash、llm 三大工具 |
| 03 | Agent 主循环 (Lua) | 可运行的 Agent 循环逻辑 |
| 04 | Anthropic API 集成 | 真实 LLM 调用 |
| 05 | 命令行测试 | Agent 实际运行 |
| 06 | 自我迭代机制 | Agent 可修改自身代码 |
| 07 | 崩溃检测与回滚 | 安全恢复机制 |
| 08 | 技能系统 | 可扩展技能架构 |
| 09 | TUI 构建 | 终端交互界面 |
| 10 | 完善与最终组装 | 完整系统 |

**严格按步骤执行，每完成一步编译验证一次。**
